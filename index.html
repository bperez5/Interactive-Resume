What I have built

Career Portfolio

A look at two projects that show how I work with data and build things people can use.

Project 1 — Financial & Economic Data Visualization in R

For this project I explored a finance and economics dataset covering three major U.S. stock indices (Dow Jones, NASDAQ, and S&P 500) along with economic indicators like inflation, unemployment, GDP growth, and oil prices. I wanted to see how the markets and the broader economy related to one another over time, so I built a set of visualizations in R using ggplot2 to explore those relationships, including two high-dimensional plots that show four and five variables at once.

View the R script →

My role: I did this project on my own from start to finish. I picked the dataset, wrote the R code, cleaned and renamed the columns so the data was easier to work with, and built every visualization myself. I chose which variables to map to color, size, and facets to get several dimensions into a single plot, and I wrote the research questions each chart was meant to answer.

Project 2 — Mortality Data Analysis in Python

For this project I worked through a full data analysis workflow in Python using pandas, taking U.S. mortality rate data by age group and year and moving it through the whole process: getting the data, cleaning it, preparing and reshaping it, running statistics on it, and visualizing the results. The goal was to see how death rates for young age groups changed over more than a century, and the final charts show a clear long-term drop in mortality, including the sharp spike around the 1918 flu pandemic.

View the Jupyter notebook →

My role: I built this project myself in a Jupyter Notebook. I wrote the Python and pandas code for every step, from reading and cleaning the data to sorting it, applying statistical functions, reshaping it with pivot and melt, grouping and aggregating it, and creating all of the visualizations. I chose how to group the data and which chart types best showed the trends in the death rates.
